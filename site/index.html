The detector sees frames. Wanyard turns them into visits: one walker, one card; a group moving together, one encounter. Then it gives you three good ways to find the moment.

Object detection, not identity surveillance.

Wanyard recognises classes such as bird, cat, dog and person. It does not recognise faces, search profiles or upload footage for somebody else to analyse.

under the hood

One camera pull, several useful views. Decoupled on purpose.

Decoupled by design.

go2rtc owns the camera connection and serves low-latency WebRTC. MediaMTX relays the recording stream; the stamper carries a frame-accurate clock in SEI metadata. Recording and detection stay independent while Spatial reconstructs synchronized frames only when asked.

  • →go2rtc pulls each camera once and fans it out
  • →Recorder never blocks on inference
  • →YOLO runs real-time on the stamped stream, backfills MP4
  • →Viewer reads from disk; no central broker
  • →Spatial cannot interrupt recording or detection

install

One docker compose up and you're recording.

Wanyard needs Docker and a directory to write footage to. The recorder and detector work immediately; experimental Spatial views are an optional CUDA setup.

QUICKSTART · CPU 
# clone, build, run
git clone https://github.com/blowhacker/wanyard.git
cd wanyard
docker compose up --build -d

# add your first camera
open http://localhost:8091/settings
QUICKSTART · GPU (CUDA) 
# enable the gpu override
cp docker-compose.gpu.yml \
   docker-compose.override.yml

docker compose up --build -d

# yolo worker now runs on cuda
docker compose logs wanyard-yolo

Hardware that's known to work

MINIMUM
A 4-core x86 box with 8 GB RAM and a 1 TB drive. Handles 1–2 cams at 1080p on CPU comfortably.
RECOMMENDED
Anything with an NVIDIA GPU (even a 1060). 4–8 cams real-time with backfill keeping pace.
SPATIAL (EXPERIMENTAL)
A CUDA-capable NVIDIA GPU and a separately downloaded VGGT checkpoint at models/vggt/model.pt. More cameras and full-density output need more VRAM.
OVERKILL
You already have a NAS and a homelab. Wanyard is happy to live in a corner of it.

faq

Things people ask.

Does this work without a GPU?
Recording and detection do. The YOLO worker runs on CPU and handles 1–2 cameras at 1080p in real time. Spatial reconstruction currently requires an NVIDIA CUDA GPU and separately downloaded VGGT weights.
What exactly is a Spatial view?
It is an interactive 3D point cloud inferred from synchronized frames from two or more overlapping cameras. Wanyard reconstructs the geometry on demand, then can project current camera colour onto it while you orbit and zoom in the browser.
Can I measure things in Spatial?
Not yet. VGGT produces coherent geometry at relative scale; it does not know how many metres apart your cameras are. Metric measurements need camera calibration. Until then, treat Spatial as an exploratory view rather than a survey instrument.
Do more cameras always make a better reconstruction?
Only when their views overlap usefully. More distinct angles can reveal more shape, but sky, reflections, motion, blank surfaces and weak overlap can create holes or noise. Wanyard checks whether a selected camera set forms a connected view before creating it.
Do I need Home Assistant?
No. Wanyard is a standalone web server. Home Assistant is great, but you shouldn't have to install a whole smart-home platform to look at your driveway.
What cameras work?
Anything that exposes an RTSP stream in H.264 or H.265. That includes most Reolink, Hikvision, Amcrest, Dahua, Tapo (with RTSP firmware), Ubiquiti, Axis, Foscam, and Annke cameras, plus generic ONVIF IP cams from before 2014. If it streams to VLC, it streams to wanyard.
Is my footage private?
By default, yes — wanyard runs LAN-only and does not upload footage or telemetry. Installation may download container layers, dependencies and model weights. If you want remote access, put it behind a Tailscale or WireGuard tunnel; don't port-forward it.
Will there ever be a hosted version?
Maybe, someday. Wanyard hosted would be for people who want all of this without owning a server. It is not the priority right now — the open-source thing is what wanyard is. If you'd find a managed version useful, drop a note on the GitHub.
What does "wanyard" mean?
Your yard is now on your WAN. Mostly a play on words; partly a reminder that the camera looking at your yard probably shouldn't be relaying through a server in Oregon.
License?
Wanyard's own code is MIT. Its dependencies and model checkpoints retain their own licences. In particular, the original VGGT checkpoint is non-commercial; choose a checkpoint whose terms fit your use.
